## Research Highlight

### Self-Improving Coding LLM — Qwen3.5-4B

Research collaboration on an end-to-end post-training and evaluation pipeline using **QLoRA / rsLoRA, distributed training, execution-based evaluation, LiveCodeBench, and RLVR**.

- Processed approximately **5M** OpenCodeInstruct samples
- Curated **1.62M** silver-quality examples
- Trained on **8,992** validated samples across **2× NVIDIA T4 GPUs**
- Held-out loss improved **46.6%**
- LiveCodeBench Pass@1 moved **20.0% → 16.67%**

The regression is part of the result: lower training loss did not translate into stronger held-out coding performance, which shifted the research toward better data selection, reward design, and evaluation.
